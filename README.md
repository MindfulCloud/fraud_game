# 🛡️ 詐騙識別實戰遊戲 (Anti-Fraud Training Game)

> **識破詐騙，破解陷阱。**
> 這是一個互動式的資安防詐訓練系統，透過模擬各種真實常見的詐騙情境，幫助使用者培養敏銳的詐騙識別能力。

🔗 **線上體驗**：[https://mindfulcloud.github.io/fraud_game/](https://mindfulcloud.github.io/fraud_game/)

---

## 📌 專案簡介 (Overview)

在數位化時代，詐騙手法層出不窮。本專案透過「遊戲化學習 (Gamification)」的方式，讓玩家在模擬情境中分析訊息、尋找可疑線索並做出防護判斷，藉此提升社會大眾與企業員工的資訊安全與防詐意識。

---

## 🎮 遊戲任務與關卡 (Game Scenarios)

專案目前包含以下多元的詐騙體驗情境：

1. **₿ 投資詐騙 (Investment Fraud)**
   * **說明**：分析可疑投資訊息、虛假獲利截圖與高報酬承諾陷阱。
   * **入口**：`investmentfraud.html`
2. **◎ Threads 求職詐騙 (Threads Job Fraud)**
   * **說明**：辨識假招聘社群貼文、可疑工作機會與要求先付款/提供個人帳戶的陷阱。
   * **入口**：`threadsjobfraud.html`
3. **🛒 網購詐騙 (E-Shop Fraud)**
   * **說明**：檢查可疑一頁式購物網站、假商品資訊與異常付款方式。
   * **入口**：`eshopfraud.html`

---

## 🕹️ 遊戲玩法 (How to Play)

1. **01 分析情境**：仔細閱讀畫面中的訊息、帳號資料、網站內容或交易紀錄。
2. **02 找出警訊**：尋找情境中隱藏的可疑線索（如不合常理的網址、高報酬誘因、催促話術等）。
3. **03 做出判斷**：選擇該情境是「安全」還是「詐騙」，即時查看詳細解析並累積積分！
